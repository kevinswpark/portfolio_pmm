# Kevin Park portfolio

English-only product marketing portfolio built from the Notion brief "Kevin Park Website", the Notion case studies "The Money Layer for Games (EN)" and "The Money Lifecycle", Kevin's WireBarley case study file, and his resume. Version 2 uses the ink ledger direction (unslopped 2026-11-10; see source/DESIGN.md).

## What's here

- `site/` is the deployable static site. Upload the folder to any static host at the domain root (Netlify, Vercel, Cloudflare Pages, GitHub Pages user site).
  - `/` home: hero with role line, introduction, selected work, About, experience, and the "Let’s talk." LinkedIn card. The nav links Work, About, and Experience to homepage sections from every page.
  - `/work/money-layer/` the first case study.
  - `/work/money-lifecycle/` the second case study, on how ZBD's products work together.
  - `/work/wirebarley/` the WireBarley case study on first-transfer conversion among customers aged 50+.
  - `/tools/financial-planner/` the financial planner: eight steps from paycheck to plan, then an email-gated PDF of the action plan. The nav's Tools menu links to it from every page.
  - `/404.html` for every missing path. The old `/en/` and `/ko/` routes from version 1 no longer exist.
- `source/` rebuilds everything.
  - `src/content.py` holds all copy. Every string is tagged with its source (BRIEF, NOTION, RESUME, ZBD, KEVIN for copy supplied in chat, or UI for added labels and buttons).
  - About portrait: `ABOUT["portrait"]` in `src/content.py` is `None`, so About renders text only. To add a photo, put it in `assets-src/` and set its file name, real pixel width and height, and alt text there, then rebuild.
  - `src/diagrams.py` draws the original diagrams. `src/site.css` and `src/site.js` hold styles and runtime.
  - `build.py` writes `dist/site/` and the single-file Artifact preview `dist/artifact/index.html`.
  - `og.py` renders the social preview card (needs the local server running).
  - `serve.py`, `verify.py`, `verify_spa.py`, `final_shots.py`: local server, Playwright checks, and review screenshots.
  - `.impeccable/sources/` keeps dated copies of the source text the checks compare against. The resume excerpt has the contact line and ZBD figures removed.
  - `DESIGN.md` and `.impeccable/design.json` document the design system, derived from the shipped build.
  - `figma/` holds the Figma scripts. See `figma/README.md` for what is already in the file and what is left to run.

## Financial planner

- Copy and the numbers it uses live in `src/content.py` under `TOOLS` and `FP`. `FP["data"]` holds the 2026 IRS limits and brackets, the cost-of-living cutoffs, the budget splits, and the savings account table with its as-of date.
- Runtime is `src/planner.js`. Answers stay in the visitor's browser (localStorage). The PDF is built in the browser with jsPDF (`vendor/jspdf-2.5.2`, MIT) and two static Mona Sans cuts in `vendor/tools/`, all loaded only when someone asks for the PDF.
- Email gate: Formspree form `xrppvnyn`, set in `FP["data"]["formspree"]`. The planner posts JSON with fetch (Formspree's AJAX method) and sends only the email, the tool name, and a subject line. A hidden `_gotcha` field catches bots. If Formspree rejects the address (422), the visitor is asked to fix it; on a network error, rate limit, or server error the PDF still downloads. Without JavaScript the form posts straight to Formspree. Set the ID to `""` to turn sending off.
- ZIP to cost of living: `src/col-data.js` is generated by `tools/make_col.py` from BEA Regional Price Parities (2024), the Census 2020 ZIP-to-county file, OMB 2023 metro areas, and Census 2024 county population. BEA publishes 2025 data on December 10, 2026; download `SARPP.zip` and `MARPP.zip` from apps.bea.gov/regional/zip/, rerun the script, and update the year in `FP["sources"]`.
- Every November: update `FP["data"]["limits"]`, `roth_phase`, `std_deduction`, and `bracket_24` from the IRS release. Refresh the savings account table whenever you touch the page; rates move with the Fed.

## Before you deploy

1. Set your domain so canonical, Open Graph, and sitemap URLs become absolute:
   `KP_SITE_URL=https://kevinpark.xyz python3 build.py` (the bundled site/ was built this way)
2. Rebuild the social card if copy changed: `python3 serve.py dist/site 8765 &` then `python3 og.py`.

## Rebuild and check

```
python3 build.py
python3 serve.py dist/site 8765 &
python3 verify.py       # static site checks at 1440, 768, and 390px, including verbatim copy against the sources
python3 verify_spa.py   # Artifact build checks
```

Requires Python 3.11 and Playwright with Chromium. Mona Sans is self-hosted from the npm Fontsource package in `vendor/`. Icons are Phosphor (regular), inlined as SVG.

## Content rules the checks enforce

- LinkedIn is the only contact route. No email, phone, or address appears anywhere.
- ZBD pipeline, attribution, and retention figures stay off the site. Finfare and WireBarley outcomes appear word for word from the resume.
- No Korean text in the build.
- The planner collects a visitor's email only through the PDF form. Kevin's own contact route is still LinkedIn only.
